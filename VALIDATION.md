# W3 validation

Run `node --test tests/*.test.mjs` from this repository, then the official Ecosystem v0.5.4 `plugin:certify-thin --repo <repository>` on a clean committed candidate.

This thin native provider has no local bootstrap, doctor, CI or release-check task; centralized certification validates manifest/skills/payload/portable archive and clean identity. Regression coverage exercises existing API success/negative cases; no Operator E2E or runtime host qualification is claimed.

B5 consumer eligibility includes Marketing, Sales, Leasing and Data against the configured CRM/customer binding. Customer Data remains a bounded CRM adapter, never the cross-role identity master; resolve canonical Person/Organization identity through WOIA Identity. Consumer eligibility does not grant update, contact, finance or competent acceptance authority.
